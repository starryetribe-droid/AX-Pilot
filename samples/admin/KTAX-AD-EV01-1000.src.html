  • 4. 콘텐츠 헤더 정보 입력
       • 4-1. 제목(메인 타이틀) 입력 인풋필드 (필수) — 프론트 카드 제목 및 상세 화면 메인 타이틀로 노출, 카드에서 최대 한 줄 노출 후 말줄임 처리되므로 권장 글자수 안내 문구 노출

       • 4-3. 행사 기간 설정 데이트피커 (필수) — 시작일 ~ 종료일 선택, 프론트 카드·상세 화면에 YYYY.MM.DD ~ YYYY.MM.DD 형태로 노출
          1) 진행 상태(진행 중/종료) 자동 판별 및 목록 정렬(진행 중 : 시작일 최신순 / 종료 : 종료일 최신순) 기준값
          2) 종료일 경과 시 자동 종료 처리 : 프론트 종료 탭 이동, 카드 Dim + 종료 표시, 상세 상태 Chip 종료 전환
          3) 시작일·종료일 모두 필수 입력 — 종료일 미입력 시 저장(등록) 불가, [저장] 클릭 시 필수값 검증 후 해당 필드 하단 에러 문구 출력 (2026-08-03)
          4) 시작일과 종료일이 동일한 경우(당일 행사) 프론트 카드에 시작일만 노출
       • 4-4. 썸네일 이미지 업로드 (필수) — 파일 첨부 방식, 업로드 후 미리보기 출력 / 권장 사이즈·용량·포맷(JPG/PNG) 안내 문구 노출

          2) [일반] 유형 선택 시 : 프론트 상세에 사전등록 관련 버튼·기능 전체 미노출

          1) 사전등록 기간은 행사 기간 내에서만 설정 가능 — 행사 기간을 벗어난 일시 선택 불가, 저장 시 검증 후 에러 문구·알럿(11-1) 출력

          2) 노출 '여' 설정 시 사전 등록 기간 설정에 따라 프론트 진행 중인 이벤트 카드 썸네일에 플래그 노출 (사전등록 기간 종료 시 자동 미노출)
          3) 행사 기간이 경과한 이벤트는 노출 '여' 설정 불가 — 행사 기간(종료일) 연장 후 그 범위 내에서 설정 가능

화면 설명

  • 메인 화면에 노출되는 배너를 등록·수정·삭제하고 노출 순서를 관리하는 목록 화면.

  • 화면 경로 : 메인 관리 > 메인 배너 관리 > 목록

  • 연결 SB : KTAX-AD-MN01-1000(배너 등록) · KTAX-AD-MN01-1100(배너 상세/수정)
    * 정의서 «3. 배너 등록/수정 팝업»은 페이지형 화면으로 확정(2026-07-22) — 별도 SB로 분리

  • 프론트 연동 : 메인 > 배너 이미지 영역
       • 5초 간격 스와이프 롤링, 최대 5건 노출
       • 클릭 시 관리자 설정 URL로 랜딩
       • 배너 1건인 경우 좌우 이동 버튼/Indicator 비노출

Description

  • 1. 헤더
       • 로그인 계정명·운영 환경 표시, 알림·로그아웃 유틸 제공

  • 2. LNB
       • 어드민 1depth 메뉴 9종, 현재 위치(메인 관리 > 메인 배너 관리) 활성 표시

  • 3. 페이지 헤더
       • 브레드크럼 + 화면 타이틀 노출

  • 4. 배너 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화
       • 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 조회 결과는 배너 리스트 테이블에 반영 (노출 순서 기준 정렬 유지)
          4-1) 검색 기준 선택 + 검색어 입력 인풋필드
             - 검색 기준 선택 셀렉박스 : 배너명 / 랜딩 URL (Default : 배너명)
             - 검색어 입력 인풋필드 (플레이스 홀더 : 검색어를 입력해 주세요)
          4-2) 노출 여부 선택 셀렉박스
             - 전체 / 노출 / 비노출 (Default : 전체)
          4-3) 등록일(기간) 선택
             - YYYY-MM-DD ~ YYYY-MM-DD 데이트피커 클릭 시 기간선택 달력 출력 (Default : 전체 기간)
          4-4) [검색] 버튼 클릭 또는 ENTER 시 조회 실행
          4-5) [초기화] 버튼 클릭 시 선택/입력된 조회 조건값 초기화
             - 모든 조건 Default 복원, 재조회 없음
          * 초기화 후 자동 재조회 여부 정책 확정 필요
             - 조회 결과 0건 시 빈 상태 표시 : '조회 결과가 없습니다.'
          * 키워드 검색 조합(검색 기준 + 검색어)은 조회 영역 맨 뒤에 배치 — 배지 번호는 정의서 번호를 따름

  • 5. 배너 리스트 테이블
       • 등록된 배너를 노출 순서 기준으로 출력
          5-1) 노출 순서 설정 : 노출 중 배너 내 순서 지정
             - 드래그 앤 드롭 또는 순서값 입력으로 변경, 변경 시 프론트 배너 롤링 순서에 반영
          5-2) 배너명 : 클릭 시 배너 상세/수정 화면으로 이동
          5-3) 배너 이미지 : 등록된 이미지 썸네일 미리보기 출력
          5-4) 랜딩 URL : 미입력 시 '-' 표시
          5-5) 노출 여부 : 노출 / 비노출 값 출력, 리스트에서 토글 변경 가능
          5-6) 등록일시 / 수정일시 : 수정 이력 없으면 '-' 표시

  • 6. [배너 등록] 버튼
       • 클릭 시 배너 등록 화면으로 이동 (KTAX-AD-MN01-1000)

  • 7. 알럿
       • 노출 최대치 알럿 : 노출(Y) 상태 배너가 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리
             - 알럿 : '메인 배너는 최대 5개까지 노출 가능합니다.'
       • 배너 삭제 : 삭제 클릭 시 확인 알럿 출력 후 삭제 처리

  • [동작 / 예외]
       • 노출 중 배너가 5건을 초과할 수 없음 — 초과 시 등록/노출 전환 차단
       • 조회 결과 0건 : '조회 결과가 없습니다.' 빈 상태 표시
       • 삭제한 배너는 복구 불가

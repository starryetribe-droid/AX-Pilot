       • 타이틀 "메인 배너 관리" + 브레드크럼 / 노출 중 건수(n/5) 안내

  • 4. 배너 리스트 테이블
       • 등록된 배너를 노출 순서 기준으로 출력
       • 4-1. 노출 순서 설정: 드래그 앤 드롭(⠿) 또는 순서값 입력으로 변경, 변경 시 프론트 배너 롤링 순서에 반영 / 노출 순서: 노출 중 배너 내 순서 지정 (비노출 "-")
       • 4-2. 배너명: 관리용 명칭 (프론트 미노출), 클릭 시 상세/수정 페이지 <KTAX-AD-MN01-1100> 이동
       • 4-3. 배너 이미지: 등록된 이미지 썸네일 미리보기 출력
       • 4-4. 랜딩 URL: 프론트에서 배너 클릭 시 해당 URL로 랜딩 / 미입력 시 배너 클릭 이동 없음
       • 4-5. 노출 여부: 노출/비노출 값 출력, 리스트에서 토글 변경 가능
       • 4-6. 등록일시 / 수정일시
       • 4-7. 배너 삭제: 삭제 클릭 시 확인 알럿(6-2) 출력 후 삭제 처리

  • 5. [배너 등록] 버튼
       • 클릭 시 등록 페이지 <KTAX-AD-MN01-1000> 이동 (IA: Page 유형 — 팝업 아님)

  • 6. 알럿
       • 6-1. 노출 최대치: 노출(Y) 상태 배너가 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리 — "메인 배너는 최대 5개까지 노출 가능합니다." + [확인]
       • 6-2. 삭제 확인: [취소]/[삭제]

  • 4. 콘텐츠 헤더 정보 입력
       • 4-1. 제목(성과 인용구) 입력 인풋필드 (필수) — 프론트 카드 제목 및 상세 화면 타이틀로 노출, 카드에서 최대 2줄 노출 후 말줄임 처리되므로 권장 글자수 안내 문구 노출 (글자수 제한 정책 확정 필요)
       • 4-2. 산업 태그 선택 셀렉박스 (필수) — 카테고리 목록 관리(PD05) '산업' 축 등록 카테고리를 호출, 프론트 카드 및 상세 화면 헤더 태그로 노출 (1개 선택)
       • 4-3. 게시일 설정 데이트피커 (필수) — 프론트 카드 및 상세 화면에 YYYY.MM.DD 형태로 노출, 프론트 목록 정렬(게시일 최신순) 기준값, Default : 등록일
       • 4-4. 대표(썸네일) 이미지 업로드 (필수) — 파일 첨부 방식, 업로드 후 미리보기 출력 / 프론트 목록 카드 썸네일 및 메인 화면 도입사례 카드 대표 이미지로 노출 / 권장 사이즈·용량·포맷(JPG/PNG) 안내 문구 노출

  • 5. 조회 조건 매핑
       • 프론트 목록 화면의 업무별·도입단계별 조회 필터 대응값 (카드·상세 화면에는 미노출)
       • 5-1. 업무 선택 (필수) — 카테고리 목록 관리(PD05) '업무' 축 등록 카테고리를 호출
       • 5-2. 도입단계 선택 (필수) — PD05 '도입단계' 축 등록 카테고리를 호출 / 업무·도입단계 각 단일 선택 (2026-07-29 확정)

  • 6. 본문 콘텐츠 입력
       • 프론트 상세 화면 본문 영역에 소제목 + 본문 순으로 노출
       • 에디터 자유 편집 방식 제공 (2026-07-29 확정) — 4개 섹션 구성은 기본 템플릿으로 제공, 섹션 추가/삭제·순서 조정 가능
       • 섹션별 소제목 수정 가능, 섹션별 노출 여부 설정 가능 (미입력·비노출 섹션은 프론트 미노출)
       • 본문 서식은 CSS 스타일 기반 HTML 에디터로 제공 (2026-07-29 확정)
       • 6-1. 프로젝트 개요 : 소제목 입력 + 본문 입력 텍스트에어리어
       • 6-2. 고객 상황 및 과제 : 소제목 입력 + 본문 입력 텍스트에어리어
       • 6-3. 적용 솔루션 및 접근 전략 : 소제목 입력 + 본문 입력 텍스트에어리어
          1) 본문 내 특정 문구(상품·서비스명 등) 강조 표기 : CSS 스타일로 제공 (2026-07-29 확정)
       • 6-4. 도입효과 : 소제목 입력 + 본문 입력 텍스트에어리어 — 고객 인용구 형태로 작성되는 항목 (제목의 성과 인용구와 연결)

  • 7. 추천 상품·서비스 설정
       • 프론트 상세 화면 하단 '추천 상품·서비스' 영역에 노출할 상품 선택
       • 7-1. [상품 불러오기] 버튼 클릭 시 상품 선택 팝업 출력 → 별도 SB <KTAX-AD-UC01-1100>
       • 7-2. 상품 선택 팝업 — 상품·서비스 관리(PD04)에 등록된 노출(Y) 상품 리스트 출력 · 검색(상품명) 및 노출 탭(솔루션 레이어) 필터 지원, 체크박스 다중 선택 후 [적용] · 최대 3건까지 선택 가능, 초과 선택 시 알럿 출력(11-1)
       • 7-3. 선택 상품 리스트
          1) 상품 정보(카테고리 태그 / 상품명 / 설명 문구)는 상품·서비스 관리(PD04) 등록 데이터를 그대로 출력, 본 화면에서 상품 내용 수정 불가
          2) 노출 순서 조정(드래그 앤 드롭 또는 순서값 입력), 연결 해제
          3) 연결 해제 시 본 도입사례에서만 제외 처리, 원본 상품은 PD04에 유지
          4) 0건인 경우 프론트 상세 화면에서 추천 상품·서비스 영역 전체 미노출
       * PD04 '도입 및 운영 효과'는 도입사례를 연결하지 않고 어드민이 직접 등록 (2026.08.03 확정) — 역방향(상품 → 도입사례) 연결 미사용, 한쪽 연결 시 반대 방향 자동 반영 없음

       • 9-2. 이미지 업로드 필드 공통(대표 썸네일·본문 이미지) 대체 텍스트(alt) 입력 — 미입력 시 제목 자동 적용

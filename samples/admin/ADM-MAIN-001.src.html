       • 연결 SB: 배너 등록/수정 팝업 = ADM-MAIN-002 · 콘텐츠 선택 팝업 = ADM-MAIN-003 (별도 페이지)
       * LNB 메뉴 구성은 워크북 미정의 — (제안)

UI 요소

  • 1. 헤더 (Top Bar · H 64px)
       • 좌: 로고 + 서비스명 "KT AX Admin" / 우: 관리자 계정 · 로그아웃

  • 2. LNB (W 260px)
       • 활성: 메인 화면 관리 (좌측 3px 바 + Bold)
       • 상품 관리·도입사례 관리·인사이트 관리 = 콘텐츠 원본 등록 서브 화면

  • 3. 페이지 헤더
       • 타이틀 "메인 화면 관리" + 브레드크럼
       • 진입 시 메인 노출 설정 조회 API 호출, 5개 섹션 일괄 출력

  • 4. 메인 배너 관리 — 배너 리스트 테이블
       • 등록된 배너를 노출 순서 기준으로 출력
       • 4-1. 노출 순서 설정: 드래그 앤 드롭(⠿ 핸들) 또는 순서값 입력으로 변경, 변경 시 프론트 배너 롤링 순서에 반영
          1) 노출 순서: 노출 중 배너 내 순서 지정 (비노출 배너는 "-")
       • 4-2. 배너명: 관리용 명칭 (프론트 미노출)
       • 4-3. 배너 이미지: 등록된 이미지 썸네일 미리보기 출력
       • 4-4. 랜딩 URL: 프론트에서 배너 클릭 시 해당 URL로 랜딩 / 미입력 시 배너 클릭 이동 없음
       • 4-5. 노출 여부: 노출/비노출 값 출력, 리스트에서 토글 변경 가능
       • 4-6. 등록일시 / 수정일시
       • 4-7. 배너 삭제: 삭제 클릭 시 확인 알럿(13-2) 출력 후 삭제 처리
       * 프론트: 5초 간격 스와이프 롤링, 최대 5건 노출, 배너 1건인 경우 좌우 이동 버튼/Indicator 비노출

  • 5. [배너 등록] 버튼
       • 클릭 시 배너 등록/수정 팝업 출력 — 상세는 별도 SB <ADM-MAIN-002>
       • 노출(Y) 상태 배너가 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리 — 알럿(13-1)

  • 6. AX 솔루션 카드 관리 — 메인 노출 콘텐츠 리스트
       • 현재 메인에 노출 중인 콘텐츠를 노출 순서 기준으로 출력
       • 6-1. 노출 순서 조정: 드래그 앤 드롭 또는 순서값 입력으로 변경 → 프론트 3*2 카드 그리드 및 스와이프 슬라이드에 순서대로 반영
       • 6-2. 콘텐츠 정보(아이콘 + 제목 + 설명 + 자세히 보기 url): 상품 관리(서브 화면)에서 등록된 데이터를 그대로 출력
          1) 본 화면에서 콘텐츠 내용 수정 불가 (노출 선택/순서 조정만 가능)
       • 6-3. 노출 해제: 해제 시 메인 노출에서만 제외 처리, 원본 콘텐츠는 상품 관리(서브 화면)에 유지
       * 워크북 원문에 "도입사례" 표기 혼입 — 문맥상 솔루션/상품 관리 (확인 필요)

  • 7. [콘텐츠 불러오기] 버튼 (솔루션)
       • 클릭 시 콘텐츠 선택 팝업 출력 — 별도 SB <ADM-MAIN-003>, 검색(솔루션명/카테고리 필터) 지원

  • 8. AX 도입사례 메인 노출 관리 — 메인 노출 콘텐츠 리스트
       • 현재 메인에 노출 중인 도입사례를 노출 순서 기준으로 출력
       • 8-1. 노출 순서 조정: 드래그 앤 드롭 또는 순서값 입력으로 변경 → 프론트 3*1 카드 그리드 및 스와이프 슬라이드에 순서대로 반영
       • 8-2. 콘텐츠 정보(성과 인용구 / 산업 태그 / 대표 이미지): 도입사례 관리(서브 화면)에서 등록된 데이터를 그대로 출력, 본 화면 수정 불가
       • 8-3. 노출 해제: 메인 노출에서만 제외, 원본 콘텐츠는 도입사례 관리(서브 화면)에 유지
       * 콘텐츠 등록/수정은 도입사례 서브 화면 관리에서 수행 · 콘텐츠 수급 후 확정 필요

  • 9. [콘텐츠 불러오기] 버튼 (도입사례)
       • 클릭 시 콘텐츠 선택 팝업 출력 — 별도 SB <ADM-MAIN-003>, 검색(제목/산업 태그) 지원

  • 10. AX 인사이트 메인 노출 관리 — 메인 노출 콘텐츠 리스트
       • 현재 메인에 노출 중인 인사이트를 노출 순서 기준으로 출력
       • 10-1. 노출 순서 조정: 드래그 앤 드롭 또는 순서값 입력으로 변경 → 프론트 3*1 카드 그리드 및 스와이프 슬라이드에 순서대로 반영
       • 10-2. 콘텐츠 정보(썸네일 이미지 / 카테고리 태그 / 제목 / 요약): 인사이트 관리(서브 화면)에서 등록된 데이터를 그대로 출력, 본 화면 수정 불가
       • 10-3. 노출 해제: 메인 노출에서만 제외, 원본 콘텐츠는 인사이트 관리(서브 화면)에 유지
       * 콘텐츠 등록/수정은 인사이트 서브 화면 관리에서 수행 · 콘텐츠 수급 후 확정 필요

  • 11. [콘텐츠 불러오기] 버튼 (인사이트)
       • 클릭 시 콘텐츠 선택 팝업 출력 — 별도 SB <ADM-MAIN-003>, 검색(제목/카테고리 태그) 지원

  • 12. 핵심 지표 관리 — 핵심 지표 리스트 (3개 항목)
       • 메인 하단 신뢰 지표 영역에 노출되는 지표 3개 항목 출력
          예: 40+ / AX 상품·서비스, AX Total Service / 5 Layer MAGIC, Alliance·Expert / 산업·기술 전문 파트너
       • 12-1. 지표값 입력 인풋필드 (수치 또는 텍스트)
       • 12-2. 설명 텍스트 입력 인풋필드
       • 12-3. 지표 수정: [저장] 클릭 시 일괄 저장
       • 텍스트만 노출 (이미지 없음, 클릭 이동 없음) / 노출 개수 3개 고정
       * 항목 추가/삭제 정책 확정 필요 (워크북 명기)

  • 4. 신청 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화 — 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 4-1. 이벤트 선택 셀렉박스 — Default : 전체 / 사전등록 폼 사용(사용 이력 포함) 이벤트 리스트 출력
          1) 이벤트 관리 목록/상세의 신청 수 클릭으로 진입 시 해당 이벤트 자동 선택
       • 4-2. 검색 기준 선택 + 검색어 입력 인풋필드
          1) 검색 기준 선택 셀렉박스 — Default : 이름 / 이름 / 이메일 + 회사명 / 연락처 (신청 항목 확장 대응, 2026-08-03)
          2) 검색어 입력 인풋필드 — 플레이스 홀더 : 검색어를 입력해 주세요
       • 4-3. 신청일(기간) 선택 — YYYY-MM-DD ~ YYYY-MM-DD 데이트피커 클릭 시 기간선택 달력 출력, Default : 전체 기간
       • 4-4. [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 4-5. [초기화] 버튼 클릭 시 선택/입력된 조회 조건값 초기화
       * 신청 상태 선택 필터 삭제 (2026-08-03 확정 — 신청 취소 기능 삭제로 전체 신청 건은 신청 완료 상태로만 관리)
       * 조건 3개 → 필터 카드 인라인 변형 / 키워드 검색 조합은 맨 뒤 배치(공통 규칙)

  • 5. 신청 리스트 테이블
       • 프론트 사전등록 폼(KTAX-FO-EV01-1100)에서 접수된 신청 내역을 신청일시 최신순으로 출력
       • 접수 데이터 적재 전용 (관리자 등록/수정 기능 없음)
       • 5-1. 이벤트명 출력
       • 5-2. 회사명 출력 (2026-08-03 컬럼 추가)
       • 5-3. 이름 출력 — 클릭 시 사전등록 신청 상세 화면(KTAX-AD-EV02-1000)으로 이동
       • 5-4. 연락처 출력 (2026-08-03 컬럼 추가) — 숫자만 최대 11자리
       • 5-5. 이메일 출력 (이메일 인증 완료된 주소)
       • 5-6. 담당 역할·업무 분야 출력 (경영진·의사결정자 / 사업·전략기획 / IT·디지털 전환 / AI·데이터 / 기타) — 舊 '직급/소속' 명칭·옵션 변경 (2026-08-03)
       • 5-7. 마케팅 수신 동의 여부 출력 (동의 / 미동의)
       • 5-8. 신청일시 출력 (YYYY-MM-DD HH:MM)
       * 신청 상태 컬럼 삭제 (2026-08-03 확정) / 컬럼 배치 순서 확정 필요 — 현재 배치는 (제안)

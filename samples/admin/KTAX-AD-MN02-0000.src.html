Description

  • 1. 헤더 (Top Bar · H 64px)
       • 좌: 로고 + "KT AX Admin" / 우: 관리자 계정 · 로그아웃

  • 2. LNB (W 260px · IA 1depth)
       • 활성: 메인 관리 › 메인 팝업 관리

  • 3. 페이지 헤더
       • 타이틀 "메인 팝업 관리" + 브레드크럼 / 노출 중 건수(n/5) 안내

  • 4. 팝업 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화 — 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 조회 결과는 팝업 리스트 테이블(⑤)에 반영 (노출 순서 기준 정렬 유지)
       • 4-1. 검색 기준 선택 + 검색어 입력
          1) 기준 셀렉박스 — Default: 팝업명 / 팝업명·랜딩 URL
          2) 검색어 인풋 — 플레이스홀더 "검색어를 입력해 주세요"
       • 4-2. 노출 여부 선택 — Default: 전체 / 전체·노출·비노출
       • 4-3. 등록일(기간) 선택: 데이트피커 클릭 시 기간선택 달력 출력 / Default: 전체 기간
       • 4-4. [검색] 클릭 또는 ENTER 시 조회 실행
       • 4-5. [초기화] 클릭 시 조회 조건값 초기화 — 모든 조건 Default 복원, 재조회 없음
       * 초기화 후 자동 재조회 여부 정책 확정 필요 / 키워드 검색 조합은 맨 뒤 배치(공통 규칙)

  • 5. 팝업 리스트 테이블
       • 등록된 팝업을 노출 순서 기준으로 출력
       • 5-1. 노출 순서: 드래그 앤 드롭(⠿) 또는 순서값 입력으로 변경, 변경 시 프론트 팝업 스와이프 순서에 반영 (비노출 "-")
       • 5-2. 팝업명: 관리용 명칭 (프론트 미노출), 클릭 시 상세/수정 페이지 <KTAX-AD-MN02-2000> 이동
       • 5-3. 팝업 이미지: 등록된 이미지 썸네일 미리보기 출력
       • 5-4. 랜딩 URL: 프론트에서 팝업 이미지 클릭 시 해당 URL로 이동 / 미입력 시 이미지 클릭 이동 없음
       • 5-5. 노출 기간: YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM 형태로 출력 / 종료일시 경과 시 자동 비노출 + «종료» 태그
       • 5-6. 노출 여부: 노출/비노출 값 출력, 리스트에서 토글 변경 가능
       • 5-7. 등록일시 / 수정일시
       • 5-8. 팝업 삭제: 삭제 클릭 시 확인 알럿(7-2) 출력 후 삭제 처리

  • 6. [팝업 등록] 버튼
       • 클릭 시 팝업 등록 화면 <KTAX-AD-MN02-1000> 출력 (IA: Page 유형)

  • 7. 알럿
       • 7-1. 노출 최대치: 노출(Y) 상태 팝업이 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리 — "메인 팝업은 최대 5개까지 노출 가능합니다." + [확인]
       • 7-2. 삭제 확인: [취소]/[삭제]
       * 삭제 확인 문구는 정의 미존재 — (제안)

  • [동작 / 예외]

  • 노출 조건
       • 프론트 노출 = 노출 여부 Y AND 노출 기간 내 / 종료일시 경과 시 자동 비노출 처리 (기간 설정 정책 확정 필요)

  • 조회 결과 0건
       • 조회 결과 0건 시 빈 상태 표시 : '조회 결과가 없습니다.'

  • 팝업 0건
       * (제안) 빈 상태 — "등록된 팝업이 없습니다. [팝업 등록]으로 추가해주세요."

  • 조회/저장 API 실패
       * (제안) "일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요."

       • 타이틀 "배너 등록" + 브레드크럼

  • 4. 배너 정보 입력 폼 (배너 등록/수정 화면)
       • 4-1. 배너명 입력 인풋필드 (필수) — 관리용 명칭 (프론트 미노출)
       • 4-2. 배너 이미지 업로드 (필수) — 파일 첨부 방식, 업로드 후 미리보기 출력 / 권장 사이즈·용량·포맷(JPG/PNG) 안내 문구 노출 (사이즈 정책 확정 필요)
       • 4-3. 배너 타이틀 입력 (필수, 글자수 제한·정책은 추후 확정)
       • 4-4. 배너 서브 타이틀 입력 (글자수 제한·정책은 추후 확정)
       • 4-5. 랜딩 URL 입력 인풋필드 — 프론트에서 배너 클릭 시 해당 URL로 랜딩 / 미입력 시 배너 클릭 이동 없음 / 새창·본창 이동 선택(라디오)
       • 4-6. 노출 여부 설정 (필수): 노출 / 비노출 선택(라디오)

  • 5. [취소] / [저장]
       • [저장]: 필수값 검증 → 노출(Y) 5건 검사 → 초과 시 알럿 "메인 배너는 최대 5개까지 노출 가능합니다." (목록 SB ⑦-1) → 통과 시 저장 후 목록 복귀, 프론트 배너 롤링 반영
       • [취소]: 미저장 종료 → 목록 복귀
       * 입력 중 이탈 확인 알럿 여부는 정의 미존재 — (제안) 즉시 이동

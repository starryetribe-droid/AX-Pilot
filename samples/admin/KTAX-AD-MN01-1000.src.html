화면 설명

  • 화면 경로 : 메인 관리 > 메인 배너 관리 > 등록

  • 연결 SB : KTAX-AD-MN01-0000(목록) · KTAX-AD-MN01-1100(상세/수정)

  • 진입 : 목록 화면의 [배너 등록] 버튼 클릭

Description

  • 1. 헤더
       • 로그인 계정명·운영 환경 표시, 알림·로그아웃 유틸 제공

  • 2. LNB
       • 어드민 1depth 메뉴 9종, 현재 위치(메인 관리 > 메인 배너 관리) 활성 표시

  • 3. 페이지 헤더
       • 브레드크럼 + 화면 타이틀 노출

  • 4. 배너 등록 폼
          4-1) 배너명 입력 인풋필드
             - 관리용 명칭 (프론트 미노출)
          4-2) 배너 이미지 업로드
             - 파일 첨부 방식, 업로드 후 미리보기 출력
             - 권장 사이즈·용량·포맷(JPG/PNG) 안내 문구 노출
          * 사이즈 정책 확정 필요
          4-3) 배너 타이틀 입력
             - MO는 줄바꿈 기능 제공 (최대 2줄)
          * 글자수 제한 정책은 추후 확정
          4-4) 배너 서브 타이틀 입력
             - MO는 줄바꿈 기능 제공 (최대 2줄)
          * 글자수 제한 정책은 추후 확정
          4-5) 랜딩 URL 입력 인풋필드
             - 프론트에서 배너 클릭 시 해당 URL로 랜딩
             - 미입력 시 배너 클릭 이동 없음
             - 새창/본창 이동 선택
          4-6) 노출 여부 설정 : 노출 / 비노출 선택
          4-7) 배너 이미지 대체 텍스트(alt) 입력 인풋필드 [2026-07-29 SEO 반영]
             - SEO·웹 접근성용, 미입력 시 배너 타이틀 자동 적용

  • 5. 저장 액션
       • [등록] 클릭 시 유효성 검사 후 저장, 저장 완료 시 목록 화면으로 이동
       • [취소] 클릭 시 입력 내용 저장 없이 목록 화면으로 이동

  • 6. 알럿
       • 노출(Y) 상태 배너가 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리
             - 알럿 : '메인 배너는 최대 5개까지 노출 가능합니다.'

  • [동작 / 예외]
       • 필수 항목(배너명·배너 이미지·배너 타이틀) 미입력 시 저장 불가
       • 노출 중 배너 5건 초과 시 노출(Y) 등록 차단
       • 등록 완료 시 노출 순서는 마지막 순번으로 부여

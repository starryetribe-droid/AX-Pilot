Description

  • 1~3. 헤더 · LNB · 페이지 헤더
       • 목록 화면과 동일 (타이틀 "인사이트 등록", 활성: 인사이트 관리 › 인사이트)

  • 4. 카테고리 선택 (필수)
       • 보도자료 / 리포트 / 미디어 중 1개 선택
       • 선택한 카테고리에 따라 본문 콘텐츠 입력 구성(⑥ 영역)이 분기됨
       • 프론트 카드·상세 화면 헤더의 카테고리 태그 및 카테고리 Chip 조회 기준값

  • 5. 콘텐츠 헤더 정보 입력
       • 5-1. 제목 입력 인풋필드 (필수) — 프론트 카드 제목 및 상세 화면 타이틀로 노출, 카드에서 최대 한 줄 노출 후 말줄임 처리되므로 권장 글자수 안내 문구 노출
       • 5-2. 요약 내용 입력 인풋필드 (필수) — 프론트 목록 카드의 요약 문구로 노출 (상세 화면에는 미노출), 카드에서 최대 한 줄 노출 후 말줄임
       • 5-3. 게시일 설정 데이트피커 (필수) — 프론트 YYYY.MM.DD 노출, 목록 정렬(게시일 최신순) 기준값, Default : 등록일
       • 5-4. 썸네일 이미지 업로드 (필수) — 파일 첨부 방식, 업로드 후 미리보기 출력 / 프론트 목록 카드 썸네일 및 메인 화면 인사이트 카드 대표 이미지로 노출

  • 6. 본문 콘텐츠 입력 (카테고리별 분기)
       • 본문 서식 : CSS 스타일 기반 HTML 에디터로 제공 (2026-07-29 확정)
       • 6-1. 보도자료 : 대표 이미지 + 본문
          1) 대표 이미지 업로드 : 상세 화면 본문 상단 노출, 업로드 후 미리보기 출력
          2) 캡션 입력 인풋필드 (선택, 2026-08-03 확정) — 이미지 하단 캡션 전용 스타일 노출, ▲ 기호 자동 표기, 미입력 시 미노출
          3) 본문 입력 텍스트에어리어 (필수)
       • 6-2. 리포트 : 대표 이미지 + 본문 + 첨부파일(PDF)
          1) 첨부파일(PDF) 업로드 : 프론트 상세 화면 [리포트 다운로드(PDF)] 버튼으로 제공
          2) 첨부 필수 아님 (2026-07-29 확정) — 미등록 시 프론트 [다운로드] 버튼 미노출 / 허용 포맷·용량 제한 안내 문구 노출 (정책 확정 필요)
       • 6-3. 미디어 : YouTube 영상 + 본문
          1) YouTube 영상 URL 입력 인풋필드 (필수) — URL 유효성 검증, 입력 시 임베드 미리보기 출력, 프론트 상세 본문 상단 임베드 노출
          2) 캡션 입력 인풋필드 (선택) / 본문 입력 텍스트에어리어 (필수)
       * 본문 에디터 내 삽입 이미지는 에디터에서 자체 처리 (캡션 인풋필드 대상 아님)

       • 7-2. 상품 선택 팝업 — 상품·서비스 관리(PD04)에 등록된 노출(Y) 상품 리스트 출력 · 검색(상품명) 및 노출 탭(솔루션 레이어) 필터 지원, 체크박스 다중 선택 후 [적용] · 최대 3건까지 선택 가능, 초과 선택 시 알럿 출력(11-1)
       • 7-3. 선택 상품 리스트 — 상품 정보(카테고리 태그/상품명/설명 문구)는 PD04 등록 데이터 그대로 출력, 본 화면에서 수정 불가 / 노출 순서 조정, 연결 해제(본 인사이트에서만 제외, 원본 상품 유지) / 0건 시 프론트 영역 전체 미노출

       • 노출 / 비노출 선택 (Default : 비노출) · 비노출 시 프론트 목록·상세 및 메인 노출 대상에서 제외

       • 9-2. 이미지 업로드 필드 공통(썸네일·대표 이미지·본문 이미지) 대체 텍스트(alt) — 미입력 시 제목 자동 적용

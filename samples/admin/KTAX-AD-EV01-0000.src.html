Description

  • 1. 헤더 (Top Bar · H 64px)
       • 좌: 로고 + "KT AX Admin" / 우: 관리자 계정 · 로그아웃

  • 2. LNB (W 260px · IA 1depth)
       • 활성: 이벤트 관리 › 이벤트 (하위: 이벤트 / 사전등록 신청)

  • 3. 페이지 헤더
       • 타이틀 "이벤트" + 브레드크럼 / 총 건수·정렬 기준 표기

  • 4. 이벤트 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화 — 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 4-1. 검색 기준 선택 + 검색어 입력 인풋필드
          1) 검색 기준 선택 셀렉박스 — Default : 제목 / 제목 / 요약 내용(서브 타이틀) / 본문
          2) 검색어 입력 인풋필드 — 플레이스 홀더 : 검색어를 입력해 주세요
       • 4-2. 진행 상태 선택 셀렉박스 — Default : 전체 / 전체 / 진행 중 / 종료
          1) 진행 상태는 행사 기간 기준 시스템 자동 판별 — 수동 조기 종료는 노출 여부(비노출)로 처리, 사전등록 조기 마감은 별도 마감 설정으로 처리 (2026-07-29 확정)
       • 4-3. 이벤트 유형 선택 셀렉박스 — Default : 전체 / 전체 / 일반 / 사전등록
       • 4-4. 노출 여부 선택 셀렉박스 — Default : 전체 / 전체 / 노출 / 비노출
       • 4-5. 행사 기간 선택 — YYYY-MM-DD ~ YYYY-MM-DD 데이트피커 클릭 시 기간선택 달력 출력, Default : 전체 기간
       • 4-6. [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 4-7. [초기화] 버튼 클릭 시 선택/입력된 조회 조건값 초기화 — 모든 조건 Default 복원, 재조회 없음 (초기화 후 자동 재조회 여부 정책 확정 필요)
       * 조건 5개 → 필터 카드 4열 그리드 변형 / 키워드 검색 조합은 맨 아래 배치(공통 규칙)

  • 5. 이벤트 리스트 테이블
       • 등록된 이벤트를 행사 시작일 최신순으로 출력
       • 5-1. 썸네일 이미지 — 등록된 썸네일 이미지 미리보기 출력
       • 5-2. 제목 출력 — 클릭 시 이벤트 상세/수정 화면(KTAX-AD-EV01-2000)으로 이동
       • 5-3. 행사 기간 출력 (YYYY-MM-DD ~ YYYY-MM-DD)
          1) 시작일과 종료일이 동일한 이벤트는 시작일만 출력(YYYY-MM-DD) — 화면설계서 기간 노출 분기 대응 (2026-08-03)
       • 5-4. 진행 상태 출력 (진행 중 / 종료 태그) — 행사 종료일 경과 시 자동 종료 전환, 프론트 종료 탭·카드 Dim 처리에 반영
       • 5-5. 이벤트 유형 출력 (일반 / 사전등록)
       • 5-6. 사전등록 신청 수 출력 — 해당 이벤트의 신청 완료 건수 기준 (신청 취소 기능 삭제, 2026-08-03 확정)
          1) 클릭 시 사전등록 신청 목록(KTAX-AD-EV02-0000)으로 이동 (해당 이벤트 필터 적용), 일반 이벤트는 '-' 출력
       • 5-7. 노출 여부 — 노출 / 비노출 값 출력, 리스트에서 토글 변경 가능 / 변경 시 확인 알럿(⑧) 출력 후 처리, 비노출 시 프론트 목록(진행 중·종료 탭)에서 제외
       • 5-8. 등록일시 / 수정일시 출력 (YYYY-MM-DD HH:MM)

  • 6. [이벤트 등록] 버튼
       • 클릭 시 이벤트 등록 화면(KTAX-AD-EV01-1000)으로 이동

  • 7. 페이지네이션
       • 7-1. 페이지당 노출 건수 선택 (10 / 30 / 50건)
       * Default 건수는 정의 미존재 — (제안) 10건

  • 8. 알럿 — 노출 상태 변경 확인
       • 토글 변경 시 확인 알럿 출력 후 처리
       * 알럿 문구는 정의 미존재 — (제안) '노출 상태를 변경하시겠습니까?'

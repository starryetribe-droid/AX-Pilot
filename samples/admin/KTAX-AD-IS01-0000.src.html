Description

  • 1. 헤더 (Top Bar · H 64px)
       • 좌: 로고 + "KT AX Admin" / 우: 관리자 계정 · 로그아웃

  • 2. LNB (W 260px · IA 1depth)
       • 활성: 인사이트 관리 › 인사이트

  • 3. 페이지 헤더
       • 타이틀 "인사이트" + 브레드크럼 / 총 건수·정렬 기준 표기

  • 4. 인사이트 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화 — 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 조회 결과는 인사이트 리스트 테이블(⑤)에 반영 (게시일 최신순 정렬 유지)
       • 4-1. 검색 기준 선택 + 검색어 입력 인풋필드
          1) 검색 기준 선택 셀렉박스 — Default : 제목 / 제목 / 요약 내용 / 본문
          2) 검색어 입력 인풋필드 — 플레이스 홀더 : 검색어를 입력해 주세요
       • 4-2. 카테고리 선택 셀렉박스 — Default : 전체 / 전체 / 보도자료 / 리포트 / 미디어
          1) 인사이트 카테고리 3종은 시스템 고정 (카테고리 추가/삭제 관리 없음, 프론트 카테고리 Chip과 동일 기준)
       • 4-3. 노출 여부 선택 셀렉박스 — Default : 전체 / 전체 / 노출 / 비노출
       • 4-4. 게시일(기간) 선택 — YYYY-MM-DD ~ YYYY-MM-DD 데이트피커 클릭 시 기간선택 달력 출력, Default : 전체 기간
       • 4-5. [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 4-6. [초기화] 버튼 클릭 시 선택/입력된 조회 조건값 초기화 — 모든 조건 Default 복원, 재조회 없음 (초기화 후 자동 재조회 여부 정책 확정 필요)
       * 조건 4개 → 필터 카드 4열 그리드 변형 / 키워드 검색 조합은 맨 아래 배치(공통 규칙)

  • 5. 인사이트 리스트 테이블
       • 등록된 인사이트를 게시일 최신순으로 출력 (프론트 목록 정렬 기준과 동일) · 수급 기준 등록 대상 : Video 3건, Text+Image 5건
       • 5-1. 썸네일 이미지 — 등록된 썸네일 이미지 미리보기 출력
       • 5-2. 카테고리 출력 (보도자료 / 리포트 / 미디어) — 프론트 카드 및 상세 화면 헤더에 노출되는 카테고리 태그
       • 5-3. 제목 출력 — 클릭 시 인사이트 상세/수정 화면(KTAX-AD-IS01-2000)으로 이동
       • 5-4. 추천 상품·서비스 수 출력 (최대 3건) — 0건인 경우 '-' 출력 (프론트 상세 화면에서 추천 상품·서비스 영역 미노출 상태임을 안내)
       • 5-5. 게시일 출력 (YYYY-MM-DD)
       • 5-6. 메인 노출 여부 출력 — 메인 관리(KTAX-AD-MN01-2100 인사이트 관리)에서 메인 노출로 선택된 콘텐츠 표시
          1) 본 화면은 표시 전용, 메인 노출 선택·순서 변경은 메인 관리에서 수행
       • 5-7. 노출 여부 — 노출 / 비노출 값 출력, 리스트에서 토글 변경 가능
          1) 변경 시 확인 알럿 출력 후 처리 (8-1)
          2) 메인 노출 중 또는 패키지 안내 배너(PD01) 연결 중인 콘텐츠를 비노출(N)로 변경 시 경고 알럿(8-2) 출력 후 메인 노출 자동 제외·배너 자동 비노출 처리 (2026-07-29 확정)
       • 5-8. 등록일시 / 수정일시 출력 (YYYY-MM-DD HH:MM)

  • 6. [인사이트 등록] 버튼
       • 클릭 시 인사이트 등록 화면(KTAX-AD-IS01-1000)으로 이동

  • 7. 페이지네이션
       • 7-1. 페이지당 노출 건수 선택 (10 / 30 / 50건)
       * Default 건수는 정의 미존재 — (제안) 10건

  • 8. 알럿
       • 8-1. 노출 상태 변경 확인: '노출 상태를 변경하시겠습니까? 변경 시 프론트에 즉시 반영됩니다.'
       • 8-2. 메인 노출·배너 연결 중 비노출 전환 경고 — 확인 시 메인 노출 자동 제외 + 배너 자동 비노출

       • 조회 결과 0건 시 빈 상태 표시 : '조회 결과가 없습니다.'

  • 프론트 노출 조건
       • 노출(Y) 콘텐츠만 프론트 목록에 노출 / 메인 노출 선택·순서는 메인 관리(KTAX-AD-MN01-2100)에서 수행

화면 정보

  •    • 화면 유형: 모달 팝업 (W 520px)
       • 부모 화면: <ADM-MAIN-001> 메인 화면 관리 — ⑤ [배너 등록] 클릭(신규) / 배너 행 수정 진입(기존 값 바인딩 — 제안)

UI 요소

  • 1. 팝업 컨테이너
       • 타이틀 "배너 등록/수정" — 배너 등록/수정 화면 (등록/수정 공용, 수정 시 기존 값 바인딩)

  • 2. 배너명 입력 인풋필드 (필수)
       • 관리용 명칭 (프론트 미노출)

  • 3. 배너 이미지 업로드 (필수)
       • 파일 첨부 방식, 업로드 후 미리보기 출력
       • 권장 사이즈·용량·포맷(JPG/PNG) 안내 문구 노출 (사이즈 정책 확정 필요)

  • 4. 배너 타이틀 입력 (필수)
       • 글자수 제한, 정책은 추후 확정 — 카운터 표기

  • 5. 배너 서브 타이틀 입력
       • 글자수 제한, 정책은 추후 확정 — 카운터 표기

  • 6. 랜딩 URL 입력 인풋필드
       • 프론트에서 배너 클릭 시 해당 URL로 랜딩
       • 미입력 시 배너 클릭 이동 없음
       • 새창/본창 이동 선택 (라디오)

  • 7. 노출 여부 설정 (필수)
       • 노출 / 비노출 선택 (라디오)

  • 8. 닫기 / 8-1. 저장
       • 8. 닫기(✕): 입력값 미저장 종료
       * 입력 중 닫기 시 확인 알럿 여부는 워크북 미정의 — (제안) 즉시 닫기
       • 8-1. [저장]: 필수값 검증 후 저장, 프론트 배너 롤링에 반영
       • 노출(Y) 상태 배너가 5건인 상태에서 노출(Y)로 등록 시도 시 등록 불가 처리 — 알럿 : '메인 배너는 최대 5개까지 노출 가능합니다.' (ADM-MAIN-001 ⑬)

동작 / 예외

  • 필수값 미입력 저장 시도
       * (제안) 해당 필드 에러 표시 — "필수 입력 항목입니다."

  • 이미지 업로드 실패
       * (제안) 실패 토스트 — "이미지 업로드에 실패했습니다. 다시 시도해주세요." / 팝업 유지

  • 노출 5건 제한
       • 저장 시점에 노출(Y) 배너 수 검사 — 5건 초과 시 등록 불가 + 알럿

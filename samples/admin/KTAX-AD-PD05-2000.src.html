Description

  • 1~3. 헤더 · LNB · 페이지 헤더
       • 목록 화면과 동일 (타이틀 "카테고리 등록", 활성: AX 도입 관리 › 카테고리 목록 관리)

  • 4. 카테고리 축 선택
       • 산업 / 업무 / 도입단계 / 솔루션 중 선택 (목록 화면에서 진입 시 선택 중이던 축이 Default)
       • 저장 후 축 변경 불가 (수정 화면에서 비활성 표시)

  • 5. 카드/섹션 정보 입력
       • 선택한 축에 따라 입력 필드 분기
          1) 산업 · 업무 · 도입단계 축 : 목록 화면에 카드로 노출 → 아이콘 + 카테고리명 + 설명 문구
          2) 솔루션 축 : 상품·서비스 목록 화면(KTAX-FO-AX05-0000)에 탭으로 노출 → 탭명 + 섹션 타이틀 + 섹션 서브카피 (아이콘 미사용)
       • 5-1. 카테고리명 / 탭명 입력 인풋필드 (필수)
          1) 산업·업무·도입단계 축: 프론트 카드 타이틀 및 카테고리 상세 화면 타이틀로 노출
          2) 솔루션 축: 프론트 탭명으로 노출 (예: Consulting / Infra / Grounding Data / AI Agent / Managed / Alliance & Expert)
          3) 동일 축 내 중복 카테고리명 등록 불가, 저장 시 검증 → 알럿(9-1) / 글자수 제한 정책은 추후 확정
       • 5-2. 아이콘 이미지 업로드 (솔루션 축 제외) — 산업·업무·도입단계 축 필수 / 솔루션 축 미사용
          1) 파일 첨부 방식, 업로드 후 미리보기 출력
          2) 권장 사이즈·용량·포맷(SVG/PNG) 안내 문구 노출 (사이즈 정책 확정 필요)
          3) 솔루션 축 선택 시 필드 비활성 (탭 노출로 아이콘 미사용)
       • 5-3. 설명 문구 / 섹션 서브카피 입력 인풋필드 (필수)
          1) 산업·업무·도입단계 축 : 프론트 카드 설명으로 노출 (글자수 제한·말줄임 정책은 추후 확정)
          2) 솔루션 축 : 상품·서비스 목록 화면의 레이어 섹션 서브카피로 노출
       • 5-4. 섹션 타이틀 입력 (솔루션 축) — 인풋필드, 솔루션 축 필수 · '전체' 탭 및 해당 탭 화면의 레이어 섹션 타이틀 (예: L1: Consulting) / 그 외 축 선택 시 필드 비노출
       • 5-5. 아이콘 이미지 대체 텍스트(alt) 입력 — 미입력 시 카테고리명 자동 적용 [SEO]
       • 5-6. URL 슬러그 입력 — 카테고리 상세 페이지 URI 관리, 제목 기반 자동 생성 + 수정 가능, 영문 소문자·숫자·하이픈(-)만 허용, 전체 콘텐츠 내 중복 등록 불가(중복 시 안내 알럿) [SEO]
          1) 카테고리 상세 화면(PD01~03 콘텐츠)의 URI는 본 슬러그를 사용 (예: /ax/industry/{슬러그})
       * 슬러그 변경 시 기존 URL 접근 처리(301 리다이렉트 vs 404) 정책 확정 필요

  • 6. 노출 상품 큐레이션 (산업·업무·도입단계 축)
       • 해당 카테고리 상세 화면(공통 템플릿)의 추천 솔루션 영역에 노출할 상품 선택
       • 상품↔카테고리 매핑은 상품·서비스 관리(PD04)가 단일 원천, 본 화면은 매핑된 상품 내에서 노출 선택·순서만 관리
       • 솔루션 축은 큐레이션 영역 비노출 (탭 화면 상품 카드는 PD04 등록 상품으로 자동 구성)
       • 6-1. [상품 불러오기] 버튼 클릭 시 상품 선택 팝업 출력 → 별도 SB <KTAX-AD-PD05-2100>
          1) 본 카테고리에 매핑된 상품이 0건인 경우 빈 상태 표시: '이 카테고리에 매핑된 상품이 없습니다. 상품·서비스 관리에서 카테고리를 매핑해 주세요.' + PD04 이동 링크
       • 6-2. 상품 선택 팝업 — 검색(상품명) 및 노출 탭(솔루션 레이어) 필터 지원, 체크박스 다중 선택 후 [적용] 시 선택 상품 리스트에 추가 · 상세는 <KTAX-AD-PD05-2100> 참조
       • 6-3. 선택 상품 리스트: 상품 정보(레이어 태그 / 상품명 / 요약 설명)는 PD04 등록 데이터를 그대로 출력, 본 화면에서 상품 내용 수정 불가
          1) 프론트 추천 솔루션 카드 문구도 PD04의 요약 설명을 그대로 노출 (카테고리별 별도 문구 미사용 — 2026-07-27 미팅 '추천 이유 텍스트 삭제' 반영)
       • 6-4. 상품 노출 순서 조정 : 드래그 앤 드롭 또는 순서값 입력으로 변경
       • 6-5. 상품 제외: 큐레이션 리스트에서만 제외 처리, 원본 상품 및 PD04 매핑 정보는 유지
       • 큐레이션 노출 개수: 최대 4건 (카테고리 상세 화면 솔루션 Card Grid 2×2 — 공통 템플릿 와이어프레임 v1.0 기준)

  • 7. 노출 설정
       • 7-1. 노출 여부 설정 — 노출 / 비노출 선택 (Default : 비노출)
       • 7-2. 노출 순서 설정 — 해당 축 카테고리 내 순서 지정 (Default : 마지막 순서)

  • 8. [저장] / [취소] 버튼
       • [저장] 클릭 시 필수값 검증 후 저장, 완료 토스트 출력 후 목록 화면으로 이동
       • 저장 시 카테고리별 콘텐츠 관리(PD01~03)에 상세 콘텐츠 등록 대상으로 생성
       • [취소] 클릭 시 확인 알럿(9-2) 출력: '작성 중인 내용이 저장되지 않습니다.'

  • 9. 알럿
       • 9-1. 카테고리명 중복: '이미 등록된 카테고리명입니다.' + [확인]
       • 9-2. 취소 확인: '작성 중인 내용이 저장되지 않습니다.' + [취소]/[확인]
       * URL 슬러그 중복 시 안내 알럿 문구는 정의 미존재 — (제안) '이미 사용 중인 URL 슬러그입니다.'

  • 5. 메인 노출 콘텐츠 리스트
       • 현재 메인에 노출 중인 인사이트를 노출 순서 기준으로 출력
       • 5-1. 노출 순서 조정: 드래그 앤 드롭 또는 순서값 입력으로 변경 → 프론트 3*1 카드 그리드 및 스와이프 슬라이드에 순서대로 반영
       • 5-2. 콘텐츠 정보(썸네일 이미지/카테고리 태그/제목/요약): 인사이트 관리(서브 화면)에서 등록된 데이터를 그대로 출력 — 본 화면에서 콘텐츠 내용 수정 불가 (노출 선택/순서 조정만 가능)
       • 5-3. 노출 해제: 메인 노출에서만 제외 처리, 원본 콘텐츠는 인사이트 관리(서브 화면)에 유지

  • 6. 전체 콘텐츠 (인라인 검색·추가)
       • 인사이트 관리에 등록된 콘텐츠 리스트 출력 — 콘텐츠 유형: Video, Text+Image (IA 명기)
       • 6-1. 검색(제목/카테고리 태그) 지원
       • 6-2. 콘텐츠 리스트 — 노출 중 콘텐츠는 [추가] 비활성 «(제안)»
       • 6-3. [추가] 클릭 = 콘텐츠 선택 시 메인 노출 리스트(⑤)에 추가

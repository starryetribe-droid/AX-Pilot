Description

  • 1. 헤더 (Top Bar · H 64px)
       • 좌: 로고 + "KT AX Admin" / 우: 관리자 계정 · 로그아웃

  • 2. LNB (W 260px · IA 1depth)
       • 활성: AX 도입 관리 › 카테고리 목록 관리
       • 하위: 카테고리 목록 관리(PD05) / 카테고리별 콘텐츠 관리(PD01~03) / 상품·서비스 관리(PD04)

  • 3. 페이지 헤더
       • 타이틀 "카테고리 목록 관리" + 브레드크럼

  • 4. 카테고리 축 선택 탭
       • 산업 / 업무 / 도입단계 / 솔루션 4개 축 탭 제공, 선택한 축의 카테고리만 리스트에 출력
       • Default : 산업
       • 축 자체는 시스템 고정 (축 추가/삭제 없음)

  • 5. 카테고리 리스트 조회 영역
       • 상세 조건 조회 및 검색/초기화 — 조회 조건 선택/입력 후 [검색] 버튼 클릭 또는 ENTER 시 조회 실행
       • 조회 결과는 카테고리 리스트 테이블(⑥)에 반영 (노출 순서 기준 정렬 유지)
       • 5-1. 검색 기준 선택 + 검색어 입력 인풋필드
          1) 기준 셀렉박스 — Default: 카테고리명 / 카테고리명·설명 문구
          2) 검색어 입력 인풋필드 — 플레이스 홀더 : 검색어를 입력해 주세요
       • 5-2. 노출 여부 선택 셀렉박스 — Default : 전체 / 전체 / 노출 / 비노출
       • 5-3. [검색] 클릭 또는 ENTER 시 조회 실행
       • 5-4. [초기화] 버튼 클릭 시 선택/입력된 조회 조건값 초기화 — 모든 조건 Default 복원, 재조회 없음 (초기화 후 자동 재조회 여부 정책 확정 필요)
       * 초기화 후 자동 재조회 여부 정책 확정 필요 / 키워드 검색 조합은 맨 뒤 배치(공통 규칙)

  • 6. 카테고리 리스트 테이블
       • 선택한 축의 카테고리를 노출 순서 기준으로 출력
          산업(공공/금융/제조/유통/의료/국방/안전·건설/서비스·기타), 업무 6종, 도입단계 4종, 솔루션(L1~L5/Alliance & Expert)
       • 6-1. 노출 순서 설정: 드래그 앤 드롭(⠿) 또는 순서값 입력으로 변경, 변경 시 프론트 목록 화면 배열 순서에 즉시 반영
          1) 산업 축 : 상위 9건이 프론트 최초 노출 대상, 10건 이후는 무한 스크롤 시 순차 노출
       • 6-2. 아이콘 (솔루션 축 제외): 등록된 아이콘 이미지 썸네일 미리보기 출력 / 솔루션 축은 아이콘 미사용(프론트 탭 노출)으로 '-' 출력
       • 6-3. 카테고리명 / 탭명: 클릭 시 상세/수정 페이지 <KTAX-AD-PD05-3000> 이동
       • 6-4. 설명 문구 / 섹션 서브카피
       • 6-5. 매핑 상품 수: 해당 카테고리에 매핑된 상품 수 뱃지 출력 (매핑은 상품·서비스 관리(PD04)에서 수행)
       • 6-6. 상세 콘텐츠 상태: 카테고리별 콘텐츠 관리(PD01~03)의 상세 콘텐츠 작성 여부 출력 — 작성 / 미작성 태그
          1) 솔루션 축은 상세 콘텐츠(PD01~03) 대상이 아니므로 '해당 없음' 출력
          2) 솔루션 축의 레이어 섹션 타이틀·서브카피는 본 메뉴에서 관리, 상품 카드는 상품·서비스 관리(PD04) 등록 상품으로 자동 구성
       • 6-7. 노출 여부: 노출/비노출 값 출력, 리스트에서 토글 변경 가능
          1) 비노출 시 프론트 목록/GNB 하위 메뉴에서 제외, 직접 URL 접근 시 404 페이지 처리
          2) 상세 콘텐츠 미작성 카테고리는 노출(Y) 변경 불가 — 변경 시도 시 안내 알럿(⑧) 출력, 콘텐츠 작성·노출 후 카테고리 노출 가능
       • 6-8. 등록일시 / 수정일시

  • 7. [카테고리 등록] 버튼 (초기 세팅 전용)
       • 클릭 시 카테고리 등록 화면 <KTAX-AD-PD05-2000>으로 이동, 현재 선택된 축이 등록 화면에 기본값으로 적용
       • 초기 데이터 세팅 전용 기능 (운영 중 카테고리 추가 없음) — 초기 구축 완료 후 버튼 비노출 또는 최고 관리자 권한 제한 처리
       * 전 축 카테고리 추가/삭제 불가 (2026-07-29 확정) — 등록 화면은 초기 데이터 세팅 용도로만 사용, IA 화면 존치 여부 확인 필요

  • 8. 알럿 — 미작성 카테고리 노출 제한
       • 상세 콘텐츠 미작성 카테고리의 노출(Y) 변경 시도 시 안내 알럿 출력
       * 알럿 문구는 정의 미존재 — (제안) "상세 콘텐츠가 작성되지 않은 카테고리는 노출할 수 없습니다."

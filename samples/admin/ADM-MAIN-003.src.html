UI 요소

  • 1. 팝업 컨테이너
       • 타이틀 "콘텐츠 선택" — 콘텐츠 선택 팝업
       • 호출 섹션별 콘텐츠 소스: 솔루션 → 상품 관리에 등록된 콘텐츠 리스트 출력 / 도입사례 → 도입사례 관리에 등록된 콘텐츠 리스트 출력 / 인사이트 → 인사이트 관리에 등록된 콘텐츠 리스트 출력

  • 2. 검색
       • 솔루션: 검색(솔루션명/카테고리 필터) 지원
       • 도입사례: 검색(제목/산업 태그) 지원
       • 인사이트: 검색(제목/카테고리 태그) 지원

  • 3. 콘텐츠 리스트
       • 섹션별 콘텐츠 정보 구성으로 출력 — 솔루션(아이콘+제목+설명+자세히 보기 url) / 도입사례(성과 인용구/산업 태그/대표 이미지) / 인사이트(썸네일 이미지/카테고리 태그/제목/요약)
       • 3-1. [선택] 클릭 시 콘텐츠 선택 시 메인 노출 리스트에 추가
       * 추가 후 팝업 유지(연속 추가) 여부는 워크북 미정의 — (제안) 유지
       * 이미 노출 중인 콘텐츠는 [선택] 비활성 — (제안)

  • 4. 페이지네이션
       * 워크북 미정의 — (제안) 10건/페이지

  • 5. 닫기
       • ✕ 클릭 시 팝업 종료, 부모 화면 리스트에 추가분 반영 상태 유지

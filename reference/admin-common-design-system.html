3.3 칩 필터 · 데이트피커 v0.2

방식 설명(가로 220px 고정)
.truncate 고객이 남긴 상담 메모입니다. 폭을 넘는 나머지는 말줄임표로 축약되고, title 속성은 JS가 셀 텍스트로 자동 채우므로 마우스를 올리면 전체 내용을 확인할 수 있습니다.
.wrap 고객이 남긴 상담 메모입니다. 폭을 넘는 나머지는 줄바꿈되어 행 높이가 내용만큼 늘어납니다.

한 줄 유지가 중요하고 전체 내용은 가끔만 필요하면 .truncate, 목록에서 바로 전체 내용을 보여줘야 하면 .wrap을 쓴다. 둘 다 기본 폭 220px이 내장돼 있어 클래스만 붙이면 동작하고, 컬럼마다 다른 폭이 필요할 때만 style="max-width:…"로 덮어쓴다. .truncate의 title 속성은 셀 텍스트를 그대로 넣어 수동으로 작성하지 않는다 — assets/js/adm-interactions.js가 셀 텍스트로 자동으로 채우고 동기화한다.

3.12 테이블 툴바 · 필터 카드 v0.2

필터 카드는 조건 개수로 변형 선택 — 1~3개 = 인라인 변형(검색 인풋 포함 한 줄, 라벨 좌측) / 4개 이상 = 그리드 변형(4열, 라벨 상단). 키워드 검색 조합(기준 셀렉트 + 검색어 인풋)은 항상 맨 아래(인라인은 맨 뒤) 배치. 툴바: 좌측 «총 N건 + 정렬·개수», 우측 «검색·설정·주요 액션».

필터 카드 (인라인 변형) — 조건 1~3개 + 검색 인풋 한 줄 (조회 목록 상단)

라벨은 컨트롤 좌측 인라인(13px/600), 컨트롤 간 28px 간격, 액션은 우측 끝 고정. 검색은 Primary 텍스트 버튼으로 통일 (아이콘 전용 돋보기 버튼 미사용 — 3.1 버튼 위계 준수).

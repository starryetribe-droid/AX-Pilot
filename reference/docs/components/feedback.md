# 토스트 · 빈 상태 (`.adm-toast`, `.adm-empty`)

원본: [admin-common-design-system_v02.html](../../admin-common-design-system_v02.html) §3.14

## 개요

토스트는 캔버스 하단 중앙(bottom 40px), 자동 소멸. 빈 상태는 테이블 영역 안 중앙 정렬.

## 클래스 계약

| 구분 | 클래스 | 설명 |
|---|---|---|
| 루트 | `.adm-toast` | 하단 중앙 알림(pill, 어두운 배경) |
| 루트 | `.adm-empty` | 빈 상태 안내(테이블/리스트 영역 중앙) |
| 내부 | `.adm-empty .t` | 빈 상태 타이틀(굵게) |

## 스펙

| 항목 | 값 |
|---|---|
| 토스트 | 배경 `rgba(25,27,31,.88)`, 텍스트 흰색, 라운드 `--r-full`, 패딩 `12px 22px` |
| 빈 상태 | 상하 패딩 64px, 중앙 정렬, 텍스트 `--g500` |

## HTML 스니펫

```html
<span class="adm-toast">텍스트가 복사되었습니다.</span>

<div class="adm-empty">
  <div class="t">조회 결과가 없습니다</div>
  검색 조건을 변경하거나 초기화 후 다시 시도해 주세요.
</div>
```

## 사용 규칙 / 금지 사항

- 토스트는 캔버스 하단 중앙에 고정 배치하고 일정 시간 후 자동으로 사라지게 한다(사용자 액션으로 닫지 않음).
- 빈 상태는 테이블/리스트를 완전히 대체하며, 검색 결과가 없을 때만 사용한다(로딩 중 상태와 혼용 금지).

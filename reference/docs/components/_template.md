# <컴포넌트명> (`.adm-xxx`)

> 이 파일은 컴포넌트 문서 공통 양식이다. 새 컴포넌트 문서 작성 시 이 구조를 그대로 복사해서 채운다.

## 개요

한 줄 용도 설명 + 핵심 사용 규칙. (원본 카탈로그의 `.desc` 텍스트 기반)

## 클래스 계약

| 구분 | 클래스 | 설명 |
|---|---|---|
| 루트 | `.adm-xxx` | 컴포넌트 루트 |
| Variant | `.adm-xxx.yyy` | 변형 설명 |
| State | `.adm-xxx.on` / `.active` / `.disabled` ... | 상태 설명 |
| 내부 요소 | `.adm-xxx .zzz` | 하위 요소 설명 |

## 스펙

| 항목 | 값 |
|---|---|
| 높이/치수 | |
| 색상 토큰 | |
| 라운드 | |

# 색상 (Colors)

기본은 무채색(Grayscale). 컬러는 상태 표현에만 사용한다 — Green(긍정·활성), Red(부정·경고), Blue(링크 전용).

원본: [admin-common-design-system_v02.html](../../admin-common-design-system_v02.html) §1.1

## Grayscale

| 토큰 | HEX | 용도 |
|---|---|---|
| `--g0` | `#FFFFFF` | 페이지/카드 배경 |
| `--g25` | `#FAFBFC` | (문서 패널 배경 등 미세 톤) |
| `--g50` | `#F5F6F8` | 필드 채움, 선택행 |
| `--g100` | `#EEF0F3` | (구분선 보조) |
| `--g200` | `#E4E7EB` | 구분선(line) |
| `--g300` | `#D3D7DD` | 인풋 테두리 |
| `--g400` | `#B0B6BF` | 텍스트(faint), 비활성 |
| `--g500` | `#8A919C` | 아이콘/보조 |
| `--g600` | `#6B7280` | 보조 텍스트 |
| `--g700` | `#4B515B` | (진한 보조 텍스트) |
| `--g800` | `#33363D` | (진한 본문) |
| `--g900` | `#191B1F` | 본문 텍스트, Primary 버튼 |

|---|---|---|
| `--green-50` | `#E9F8F1` | 태그 배경 |

| `--green-600` | `#0C8E60` | 토글 ON, 긍정 |

## Dark Surface — 다크 배경 전용

라이트(Grayscale) 기반 화면 안에서 LNB 등 일부 영역만 다크 서페이스로 띄울 때 쓴다. 페이지 전체 다크 모드가 아니라 `.adm-gnb.dark`처럼 컴포넌트 단위 변형에 한정한다.

| 토큰 | HEX | 용도 |
|---|---|---|
| `--dark-bg` | `#2b2e3a` | 다크 서페이스 기본 배경 |
| `--dark-bg-strong` | `#1e2028` | 다크 서페이스 강조 배경(헤더 등 더 어두운 블록) |
| `--dark-active-bg` | `rgba(255,255,255,.08)` | 다크 서페이스 안의 선택/활성 행 배경 |
| `--dark-text` | `#ffffff` | 다크 서페이스 기본 텍스트 |
| `--dark-text-sub` | `#9aa0ac` | 다크 서페이스 보조 텍스트 |

## Semantic

| 토큰 | 값 | 용도 |
|---|---|---|
| `--text` | `#222222` | 기본 본문 텍스트 |
| `--text-sub` | `#666666` | 보조 텍스트 |
| `--text-mute` | `#888888` | 흐린 보조 텍스트(플레이스홀더 등) |
| `--text-faint` | `#bbbbbb` | 가장 흐린 텍스트(비활성, 헬퍼) |
| `--line` | `#E4E7EB` (=g200) | 기본 구분선 |
| `--line-strong` | `#D3D7DD` (=g300) | 강조 구분선, 인풋 테두리 |
| `--bg-page` | `#FFFFFF` | 페이지 배경 |
| `--bg-fill` | `#F5F6F8` (=g50) | 채움 배경 |

## 사용 규칙

- 컴포넌트 CSS에서는 원시값(hex)을 직접 쓰지 않고 토큰(`var(--*)`)만 참조한다.
- Green/Red/Blue는 상태 표현 전용이며 장식 목적으로 사용하지 않는다.
- Blue는 텍스트 링크(`.adm-link`)에만 사용한다.
